# Controller action hierarchy

The Controller shows the observable product surface: streaming output and durable log-file actions. Its contextual copy action copies selected output when present, otherwise the invoked row, so a user can retain a diagnostic without exposing a generic web context menu. It does not repeat the internal `pnpm dsh web` invocation as a command card, because users cannot safely act on its Launcher patch arguments. The managed child action lives in the persistent route footer and reuses the Launch action's size, emphasis, and state treatment; the running state uses a stop glyph while preserving the same button geometry. Child-state polling reads fresh data silently: it does not disable controls or produce a route-enter animation, so a running process cannot make a version list flicker.
