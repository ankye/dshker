# 2026-09-18 – Release 0.1.60 (5 user-facing fixes)

## Changes since 0.1.59

- **Nav rename: Run → Browser / 运行 → 浏览器.** The left sidebar item that
  opens the DSH Web workbench view now reads "Browser" instead of "Run".
- **Tab highlight.** Selected browser tab now has an accent underline
  (`::after` pseudo-element), making the active tab unmistakable.
- **Network ID always visible + copy button.** Moved the network id + copy
  button out of the expandable "manage network" editor into the network
  selection row itself (always visible).
- **Clear output button in console.** Added a "clear" action to the console
  action bar (`harnessConsole.value = []`); the disk log file is unaffected.
- **resumeConnectivity() on connect IPC.** User-triggered connect now clears
  auto-connect backoff before dispatching, ensuring an immediate retry after an
  overnight drop instead of waiting up to 60s for the next sweep.
